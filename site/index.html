Azure and Entra ID for MCP, read-only by default.

Give a model the whole Azure CLI, one command to one tool call, without giving it the keys to everything. Every az command is classified before it runs, and each tier sits behind a gate that only the operator can open.

Safety model

The design assumes the model will sometimes be wrong or be talked into something by content it reads, such as a resource tag or a log line. The operator decides what is possible; the model only decides what to ask for within that.

Read

Nothing to open

List_*, Get_*, Query_*, views and Az_CLI.

Write

AZURE_MODE=write

Creates, updates, starts, tags and credential reads. Each call also needs confirm: true.

Destructive

Plus AZURE_ALLOW_DESTRUCTIVE=true

Delete, stop, restart, resize, purge and run-code. Needs both settings and confirm: true.

Write tools stay listed in read mode and refuse with a message that names the setting, so a refusal is explainable. Remotely, the caller also needs the Azure.Write or Azure.Destructive Entra app role, and everything is bounded by the identity's own Azure RBAC.

The CLI is classified, not trusted

Command words are lowercased like the CLI does, long options match their abbreviations, repeated options are all checked, and global options do not hide a command. Reads that return keys, secrets or connection strings count as writes. Login, config, interactive sessions and anything that reaches local files are always refused.

Install

Needs Node.js 20 or later and the Azure CLI signed in with az login. With no settings it runs read-only as your sign-in.

Features

The whole Azure CLI

Az_CLI for reads, Az_CLI_Run for the rest at the tier each command earns, Az_CLI_Help for arguments.

Microsoft's server, gated

Every tool of the pinned @azure/mcp, proxied one-to-one and gated per command.

Tenant profiles

One server across several Entra tenants, with service principals or your az login, chosen per call.

Interactive views

Estate, virtual machines, web apps, costs, resources, security, tenants and an Azure Services explorer, rendered inline by MCP Apps hosts.

Two transports

Local stdio, or Streamable HTTP on Container Apps where every call runs as the signed-in user via on-behalf-of.

Tested without Azure

The test suite drives the server with a fake az and never signs in. Classifier changes need a test that fails without them.
